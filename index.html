One‑Time Setup (Takes 5 Minutes)

Before you can separate your first track, you need to install Python 3 and Demucs. This is only needed once.

1. Install Python 3

Open Terminal (press ⌘+Space, type "Terminal", hit Enter) and paste:

/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

Follow the on‑screen instructions. Then, when Homebrew is ready, type:

brew install python@3.12

2. Install Demucs

In the same Terminal window, run:

pip3 install demucs

That's it! The first time you use DeepStem, the AI model will download automatically (a couple of minutes). After that, everything runs offline.

Optional: For extra format support (AIFF, M4A), install ffmpeg:
brew install ffmpeg
