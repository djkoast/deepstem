One‑Time Setup Guide

Before you can separate your first track, you need to install Python 3 and the Demucs library. This takes about 5 minutes and only needs to be done once.

Step 1: Install Python 3

Open the Terminal app (press ⌘+Space, type “Terminal”, hit Enter) and paste this line:

/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

Follow any on‑screen prompts. When Homebrew is ready, run:

brew install python@3.12

Step 2: Install Demucs

In the same Terminal window, run:

pip3 install demucs

That's it! The first time you use DeepStem, the AI model will download automatically (this takes a few minutes, but only once).

Optional: For extra audio format support (like AIFF and M4A), install ffmpeg by running:
brew install ffmpeg
